# PlanYours

Your AI-powered trip planner.

## Project info

A modern, full-stack travel planning application built with React, Vite, and Node.js.

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Node.js & Express (Backend)
- MongoDB (Database)

## Getting Started

Follow these steps to run the project locally:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies for frontend
cd frontend
npm install

# Step 4: Start the frontend development server
npm run dev

# Step 5: (Optional) Start the backend server
# Navigate to the backend directory and follow backend instructions
```
